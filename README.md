# LocalBox

Локальный сервер для игр Jackbox с веб-клиентом, озвучкой и поддержкой Додо Ре Ми.

[Скачать](https://github.com/zAsQwE/localbox/releases) · [Telegram](https://t.me/lacalbox)

## Установка

Скачайте установщик из **Assets** на странице Releases:

| Система | Файл |
| --- | --- |
| Windows 10/11 x64 | `setup.exe` |
| Linux | `setup-linux.run` |

На Linux:

```sh
chmod +x setup-linux.run
./setup-linux.run
```

Выберите папку установки, озвучку и голоса, затем нажмите **«Скачать»**.
Для Додо Ре Ми укажите папку Jackbox 10; для читов можно выбрать папку с играми.
Отметьте «Скачать русский веб-клиент», чтобы установить `client-ru.zip` из того же Release.
Setup скачает последний стабильный Release и недостающие зависимости.
Уже установленные совместимые программы используются повторно.
Для установки нужен интернет. Игры Jackbox устанавливаются отдельно.

## Запуск

1. Откройте ярлык LocalBox, `start-server.bat` на Windows или `./start-server.sh` на Linux.
2. В лаунчере выберите IP компьютера и нажмите **«Запустить»**.
3. В параметрах запуска игры в Steam укажите `-jbg.config serverUrl=ВАШ_IP`.
4. Игроки открывают `https://ВАШ_IP` или сканируют QR-код комнаты.

Сертификат сохраняется локально и не добавляется в доверие. Браузер может показать
предупреждение HTTPS; игры со строгой проверкой TLS могут отклонить подключение.

## Обновления

Нажмите **«Проверить обновления»**, затем **«Обновить до …»**.
LocalBox установит новый Release и перезапустит лаунчер, сохранив настройки и скачанные данные.
Перед обновлением завершите игровую сессию.
