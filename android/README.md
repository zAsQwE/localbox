# LocalBox Android · 0.1.12-dev

Сервер LocalBox прямо на телефоне: Android 7+, ARM64 или x86_64. Компьютер, Termux и root не нужны.

## Как играть

1. Установите `LocalBox-android-dev.apk`.
2. В **«Настройках»** скачайте веб-клиент: `client` (английский) или `client-ru` (русский).
3. Нажмите **«Патч из установленной игры»** (или **«Выбрать APK для патча»**), укажите порт игры и
   **«Создать APK для LocalBox»**. Установите полученную копию: она встанет рядом с оригиналом
   под именем «… · LocalBox», удалять игру не нужно.
4. Запустите сервер на том же порту и откройте копию игры.
5. Игроки в той же Wi-Fi-сети сканируют QR или открывают адрес из LocalBox.
   **«Играть на этом телефоне»** открывает игру для игрока прямо в приложении.

Порты по умолчанию: игра — `5555` (если занят ADB, возьмите `5557`), сайт игроков — `8080`.

## Что важно знать

- **Патч** перенаправляет игру на LocalBox по HTTP/WS внутри телефона. Оригинальная игра и её файлы
  не меняются: создаётся копия со своим именем пакета (`….localbox`) и подписью, поэтому Android ставит
  её рядом с оригиналом. Данные у копии свои: при первом запуске она может заново скачать файлы игр.
  Если какая-то игра не запускается с новым именем, снимите галочку **«Ставить копию рядом с оригиналом»**:
  тогда копия заменяет оригинал, и его нужно удалить перед установкой.
  Поддерживаются игры на Ecast и Java-Blobcast; Unity и неизвестные сборки патчер честно отклоняет.
- **Проверено:** JPP7 RU 1.0.2 и JPP1 RU 1.1.0 — создание комнаты, WebSocket и блокировка комнаты.
  Полные партии и другие сборники ещё не проверены.
- **VPN-перенаправление** выключено по умолчанию и работает только для игр на `http://` и `ws://`.
  Игры на HTTPS (например JPP7 RU) через VPN не подключатся — для них нужен патч, LocalBox сообщит об этом сам.
- **HTTPS для сайта** можно включить в настройках (порт `8443`). У LocalBox на телефоне свой CA, он не
  заменяется автоматически; публичный CA отдаётся по `https://IP_ТЕЛЕФОНА:8443/localbox-ca.crt`.
  Без доверия к нему браузер покажет предупреждение, поэтому проще оставить обычный HTTP.
- **QR** показывается в лобби, его можно закрыть и вернуть. Включается и окно QR поверх игры
  (Android спросит разрешение), его можно перетаскивать.
- **Озвучка** использует офлайн-голоса, уже установленные в Android. Если таких голосов нет, игра
  идёт без озвучки, ничего не скачивается.
- **Не поддерживаются:** рендер Додо Ре Ми и image-сущности Hyperface.

## Сборка

Нужны Go 1.26+, JDK 17+, Android SDK (platform 34), NDK и Gradle 8.13:

```sh
python3 android/tools/build.py --sdk "$ANDROID_HOME"
```

Результат — `android/dist/LocalBox-android-dev.apk` и `SHA256SUMS` (debug-сборка; для публикации
нужна своя release-подпись).

Тесты:

```sh
(cd android/server && go test -race ./...)
(cd android/vpn && ./gradlew testDebugUnitTest)
```

Тесты на устройстве (`androidTest`) частично требуют личных APK игр, они в репозиторий не входят:
`LOCALBOX_TEST_APK=/путь/к/игре.apk` и `LOCALBOX_ECAST_APK=/путь/к/JPP7.apk` для unit-тестов,
`files/fixture-*.apk` в данных приложения для тестов на устройстве.

Библиотека CRDT — [go-yjs](https://github.com/antst/go-yjs) v0.1.1 (MIT), лицензия в APK: `assets/licenses/go-yjs.txt`.
