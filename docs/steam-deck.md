# LocalBox на Steam Deck

Сервер работает прямо на Deck, в игровом режиме, без ПК и без интернета: игры подключаются к нему,
телефоны игроков — к раздаваемому им веб-клиенту. Для игровых режимов есть обёртка параметров
запуска и QR-код для входа поверх игры.

Файлы — в `tools/steamdeck/`:

| Файл | Назначение |
| --- | --- |
| `install.sh` | установка: Node.js, зависимости, служба `localbox` |
| `jackbox.sh` | параметры запуска Steam: выбор сервера одним флагом |
| `qr-overlay.py` | QR-код для игроков поверх игры (gamescope) |

## Установка

В режиме рабочего стола, в Konsole:

1. Распакуйте LocalBox (Release или `git clone`) в любую папку, например `~/LocalBox`.
2. Положите веб-клиент в `client-ru/` или `client/` (см. [ручную установку](manual.md)).
3. Запустите установку:

   ```sh
   ~/LocalBox/tools/steamdeck/install.sh
   ```

   Скрипт скачает переносимый Node.js в `runtime/node` (SHA-256 сверяется с nodejs.org),
   поставит зависимости сервера, создаст `server/config.json` и пользовательскую службу `localbox`.
   Повторный запуск безопасен — так же обновляются пути после переноса папки.
4. Выполните одну команду, которую скрипт напечатает в конце (нужен пароль):

   ```sh
   sudo setcap cap_net_bind_service=+ep ~/LocalBox/runtime/node/bin/node
   ```

   Игра подключается к комнате только по `wss` на порт 443, поэтому без этого права не обойтись.
   Брандмауэр трогать не нужно: телефоны ходят на высокий порт (см. ниже).

## Параметры запуска

Steam → игра → **Свойства → Параметры запуска**, для каждого пака Jackbox:

| Режим | Строка |
| --- | --- |
| Локально (LocalBox на Deck, без интернета) | `~/LocalBox/tools/steamdeck/jackbox.sh -local %command%` |
| Российские серверы (jb-ecast.klucva.ru) | `~/LocalBox/tools/steamdeck/jackbox.sh -online-ru %command%` |
| Официальные серверы игры | `~/LocalBox/tools/steamdeck/jackbox.sh -online %command%` |
| Режим по умолчанию | `~/LocalBox/tools/steamdeck/jackbox.sh %command%` |

Режим по умолчанию меняется командой `jackbox.sh mode local|online-ru|online`.
`jackbox.sh status` показывает режим, IP, состояние сервера и адрес для игроков.
Журнал запусков — `~/.local/state/localbox/launch.log`, журнал сервера — `server.log` там же.

В режиме `-local` обёртка при каждом запуске:

- определяет текущий IP Deck; если сеть сменилась, перевыпускает сертификат и обновляет `serverUrl`;
- запускает службу `localbox`, если она не работает, и ждёт порт 443;
- передаёт игре `-jbg.config serverUrl=IP -cafile certs/localbox.pem` — игра доверяет
  локальному сертификату, системное хранилище не меняется.

## Игроки и QR-код

| Режим | Игрокам | QR поверх игры |
| --- | --- | --- |
| `-local` | `http://IP_DECK:38202` | с кодом комнаты; виден в лобби, исчезает с началом партии |
| `-online-ru` | `https://jackbox.ru` | на сайт; в меню и 30 с после создания комнаты |
| `-online` | `https://jackbox.fun` | на сайт; в меню и 30 с после создания комнаты |

Почему 38202, а не 80: обновления SteamOS возвращают брандмауэр к настройкам по умолчанию, где
порты 80 и 443 закрыты для сети, а 1024–65535 открыты. Если 38202 занят другой программой,
сервер берёт следующий свободный порт; QR и `jackbox.sh status` всегда показывают фактический.

В онлайн-режимах комнату создаёт внешний сервер, поэтому код игроки вводят с экрана игры, а QR
ведёт только на сайт. Время показа — `LOCALBOX_QR_SECONDS`, отключить QR — `LOCALBOX_QR=0`, например
`LOCALBOX_QR=0 ~/LocalBox/tools/steamdeck/jackbox.sh -local %command%`.

## Ограничения

- QR-оверлей виден только в игровом режиме (gamescope рисует его в левом верхнем углу).
- Публичный Wi-Fi часто изолирует устройства друг от друга — тогда телефоны не увидят Deck.
  Раздайте сеть с телефона и подключите к ней Deck и остальных.
- IP выбирается при запуске игры. Если Deck переподключился к сети посреди партии — перезапустите игру.

## Что проверено

Боты (настоящий веб-клиент в браузере) сыграли полные партии на Deck без интернета, с русским клиентом:
Party Pack 4 — все 5 игр (включая рисование в «Гражданском холсте»), Party Pack 5 — все 5
(рисунки в «Творим патенты», рогатка в «Купол Зипол», озвучка в «Городе злых рифм»), Party Starter —
Quiplash 3. В «Раздели комнату» начало партии подтверждается кнопкой в самой игре, не с телефона VIP.
