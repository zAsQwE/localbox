# Игра с друзьями через Porthole (без проброса портов и публичного IP)

[Porthole](https://store.steampowered.com/app/4963920/Porthole__Local_Port_Sharing/) — это
Steam-прокси портов (аналог Hamachi/Radmin, но через сеть Steam): ты делишься выбранным портом со
Steam-друзьями, и они подключаются к твоему сервису **как будто он запущен у них на localhost**.
Никакого проброса портов, публичного IP и настройки роутера.

Для LocalBox это идеально: ты хостишь игру и сервер локально, друзья заходят на портал через Porthole.

## Что для этого есть в LocalBox
Клиент подключается к комнате по адресу, который сервер возвращает в инфо о комнате
(`room.host`). LocalBox теперь возвращает игроку **тот адрес, по которому он сам достучался**
(Host-заголовок), а не фиксированный `serverUrl`. Поэтому:
- **Porthole-друг** пришёл через свой `localhost` → и обратно (портал, API, WebSocket) идёт на свой
  `localhost` → Porthole тянет к тебе. Работает, даже если Porthole пробросил на другой локальный порт
  (порт сохраняется).
- **LAN-игрок** пришёл на LAN-IP → идёт на LAN-IP. Локальный — на localhost. Всё одновременно.

Отдельно ничего включать не надо — работает само.

## Настройка (по шагам)

**У тебя (хост):**
1. В лаунчере «Адрес сервера» → `127.0.0.1` (сервер и Steam-игра общаются локально; серт mkcert
   покрывает `127.0.0.1` и `localhost`). Выдай серт, разреши порты, запусти.
2. Запусти игру в Steam с параметром `-jbg.config serverUrl=127.0.0.1`, создай комнату.
3. Открой **Porthole** и **поделись портом LocalBox** со Steam-друзьями. Порт выбирай по вкусу:
   - **80 (HTTP)** — проще всего: у друзей **не будет** возни с сертификатом.
   - **443 (HTTPS)** — если хочешь HTTPS; тогда см. про серт ниже.
   - (Портала и игрового Ecast-трафика хватает **одного** порта — они на одном порту.)

**У друзей (игроки):**
1. Поставить Porthole, подключиться к тебе (по Steam-дружбе).
2. Открыть в браузере портал на своём localhost — тем же портом, что ты расшарил:
   - `http://localhost/` (если поделился портом 80) — без сертификата, самый простой путь.
   - `https://localhost/` (если 443) — браузер покажет предупреждение о серте (см. ниже).
3. Ввести **код комнаты** и имя → играть.

## Про сертификат
- **По HTTP (порт 80)** сертификат не нужен вообще — самый беспроблемный вариант для друзей.
- **По HTTPS (порт 443)** серт mkcert покрывает `localhost`, но подписан твоим локальным CA, которому
  браузер друга не доверяет. Варианты: друг нажимает «принять риск» (для localhost обычно достаточно),
  либо ты передаёшь ему `rootCA.pem` mkcert и он ставит его как доверенный (см. `mkcert -CAROOT`).

## Частые вопросы
- **Сколько портов шарить?** Одного (80 **или** 443) достаточно — портал, API и WebSocket у LocalBox
  на одном порту. Порты `38202/38203` — только для Android без root, для Porthole не нужны.
- **Друзья видят «не могу подключиться» после ввода кода?** Значит `room.host` уводит не туда — проверь,
  что открываешь портал именно на `localhost` (том же порту, что расшарен), а не на LAN-IP.
- **Свой код комнаты** (в т.ч. русский) — работает вместе с Porthole (см. настройку кода в лаунчере).
