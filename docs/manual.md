# Ручная настройка LocalBox

Для обычной установки используйте setup из [Releases](https://github.com/zAsQwE/localbox/releases).

## Требования для ручной установки

Сервер написан на **Node.js**, лаунчер — на **Python** (запускается через `python3 localbox_launcher.py`). Оба нужны на любой ОС.

### Windows

| Что                     | Обязательно | Как поставить                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Node.js**                | да                   | Скачать LTS-установщик с https://nodejs.org (`.msi`), установить (npm входит в комплект). Проверка в `cmd`: `node -v`.                                                                                                                                                                                                   |
| **Python 3**               | да                   | https://python.org → при установке отметить**«Add python.exe to PATH»**. tkinter входит в установщик Windows.                                                                                                                                                                                                                        |
| **OpenSSL**                | желательно    | LocalBox создаёт собственный локальный CA и подписывает им сертификат выбранного IP. Если OpenSSL недоступен, лаунчер автоматически использует переносимый mkcert. |
| Права на порты | **не нужно**    | Windows разрешает порты 80/443 без спец-действий. Кнопку «Разрешить порты» на Windows жать не надо.                                                                                                                                                                                                           |

### Linux

Node.js по дистрибутивам:

```sh
# Debian / Ubuntu (свежий node):
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt-get install -y nodejs
# Arch / CachyOS:
sudo pacman -S nodejs npm
# Fedora:
sudo dnf install nodejs npm
```

| Что                            | Обязательно          | Как поставить                                                                                                                                                           |
| --------------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Node.js**                       | да                            | см. выше                                                                                                                                                                      |
| **Python 3**                      | обычно уже есть    | `python3 --version`; иначе `sudo apt install python3` / `sudo pacman -S python` / `sudo dnf install python3`.                                                                  |
| **tkinter**                       | для GUI                      | Debian:`sudo apt install python3-tk` · Arch: `sudo pacman -S tk` · Fedora: `sudo dnf install python3-tkinter`. Для серверного режима (`-ip=`) не нужен. |
| **OpenSSL** | желательно | Debian: `sudo apt install openssl` · Arch: `sudo pacman -S openssl`. Сертификаты создаются только в папке LocalBox. |
| **git**                           | для клонирования | `sudo apt install git` / `sudo pacman -S git`.                                                                                                                                      |
| Права на порты 80/443 | да                            | Либо запуск от root (`sudo`), либо `setcap` для node — лаунчер делает это сам через `sudo`/`pkexec`.                                    |

### macOS (кратко)

```sh
brew install node openssl       # node обязателен; openssl выпускает LocalBox CA
brew install python-tk          # если нужен GUI
```

Порты 80/443 на macOS требуют запуска от root (`sudo`).

## Быстрая установка

### Linux / macOS

Запустите **`setup-linux.run`** из готовой сборки или **`./setup.sh`** из исходников.
В одном окне выберите папки приложения и зависимостей, TTS, голоса и путь к Jackbox 10,
затем нажмите «Скачать». Оформление следует светлой или тёмной теме окружения.
Python 3.10+, Tk, Node.js, npm, ffmpeg, git и OpenSSL устанавливаются автоматически при необходимости.

```sh
./setup.sh          # окно скачивания (в отсутствие дисплея — меню в терминале)
./setup.sh --console # текстовый мастер
./setup.sh --ru     # + русский клиент client-ru.zip из Release
./setup.sh --run    # установить и сразу запустить
```

Запуск после установки — **`./start-server.sh`**: выбор GUI, поддержки Додо Ре Ми и установленного голоса.
Или напрямую: `cd launcher && python3 localbox_launcher.py`.

### Windows

Запустите **`setup.exe`** из готовой сборки. Выберите папку LocalBox, отдельную папку зависимостей,
TTS и голоса. Для Додо Ре Ми можно указать папку установленного Jackbox Party Pack 10:
музыка и доступные сэмплы будут скопированы автоматически. Нажмите «Скачать» — установщик подготовит Python с Tk,
Node.js, ffmpeg, MinGit, mkcert, зависимости сервера и выбранные TTS-библиотеки и модели.
Установленный подходящий Python может быть использован повторно.
Окно автоматически следует светлой или тёмной теме приложений Windows.

Из исходников **`install.bat`** открывает готовый `dist/setup.exe`, если он есть, иначе устанавливает
в текущую папку через PowerShell с выбором TTS. Повторно открывать окно для обновления PATH не нужно.
Запуск — **`start-server.bat`**: сначала вопросы о GUI, Додо Ре Ми и установленном голосе.

Подробности и сборка установщиков: **[docs/install.md](install.md)**.

Ниже — то же вручную и подробно.

## Первая настройка (подробно)

В репозитории **нет тяжёлых частей** (они в `.gitignore`): зависимостей движка (`node_modules`) и веб-клиентов (`client/`, `client-ru/`). Их нужно получить один раз.

**1. Получить проект**

```sh
git clone https://github.com/zAsQwE/localbox localbox
# или скачать ZIP и распаковать
```

**2. Проверить структуру папок** — рядом должны лежать:

```
localbox/
  server/        ← игровой сервер (наш)
  launcher/      ← лаунчер
  client-ru/  и  client/   ← веб-клиент для телефонов (см. шаг 4)
```

Если есть только `launcher/` — скопирован не весь проект.

**3. Установить Node.js** (см. «Требования» для своей ОС).

**4. Получить веб-клиент** (хотя бы одну папку). Сами клиенты в этот репозиторий **не входят** (это ассеты Jackbox) — их скачивают отдельно из исходных источников:

- **Английский клиент `client/`** — из стороннего репозитория [DdejjCAT/jackbox.tv](https://github.com/DdejjCAT/jackbox.tv) (полный набор ассетов):

  ```sh
  git clone https://github.com/DdejjCAT/jackbox.tv client
  ```
- **Русский клиент `client-ru/`** — качается с jackbox.ru встроенным скриптом:

  ```sh
  node tools/fetch-fun.js --host jackbox.ru --dst client-ru
  ```

  Можно ограничиться тонкой оболочкой: **недостающие текстуры движок докачает с jackbox.ru при первой загрузке и закэширует** (интернет нужен один раз, дальше офлайн).

**5. Зависимости движка** — установятся сами при первом запуске лаунчера, либо вручную:

```sh
cd server && npm i
```

**6. Запускать** — см. ниже (Windows GUI или Linux-сервер).

## Запуск — Windows (с интерфейсом)

1. Двойной клик по **`start-server.bat`**: выберите GUI, режим Додо Ре Ми и голос из установленных.
   Выбор Додо Ре Ми синхронизируется с галочкой в настройках, включая её отключение.
2. При необходимости откройте **⚙ Настройки** справа сверху и укажите локальный IP сервера.
3. Нажмите **▶ Запустить**. Лаунчер создаст локальный сертификат и проверит права на порты.
4. Логи движка выводятся в консоль, из которой запущен лаунчер.
5. После создания комнаты справа внизу появится QR-код для входа игроков.

## Запуск — Linux (сервер, без GUI)

> Может быть небезопасно — для игры с друзьями, не как публичный сервис.

```sh
cd launcher
python3 localbox_launcher.py -ip=АЙПИ_СЕРВЕРА            # с веб-клиентом (игроки заходят на https://АЙПИ)
python3 localbox_launcher.py -ip=АЙПИ_СЕРВЕРА -no-web    # только игровой сервер, без раздачи сайта
```

Команда сама: сгенерирует сертификат под этот IP, пропишет `config.json`, выдаст node права на порты 80/443 (через `sudo`/`pkexec`), поставит зависимости и запустит движок. Лог — в терминал, остановка — `Ctrl+C`.

**Если права на порты не выдались автоматически:**

```sh
sudo setcap cap_net_bind_service=+ep "$(command -v node)"
```

Кнопка **«Сертификат»** создаёт сертификат и ключи в `certs/`.
LocalBox не добавляет их в доверие системы, браузеров или Steam.
Браузер может запросить исключение; игровой клиент со строгой проверкой TLS
может отклонить такой сертификат. Подробнее: [установка и сертификаты](install.md#сертификаты).

## Подключение игры (хост)

В Steam → свойства игры → **Параметры запуска**:

```
-jbg.config serverUrl=АДРЕС_СЕРВЕРА
```

(`127.0.0.1` для локальной игры или IP сервера в сети). hosts-файл и VPN не нужны.

## Подключение игроков

Отсканируйте QR-код справа внизу экрана: откроется локальный сайт с уже введённым кодом комнаты.
При нескольких мониторах QR появляется на экране с лаунчером и перемещается вместе с ним.
После начала партии QR скрывается автоматически. При создании новой комнаты он появляется снова.
Игроку останется указать имя. QR открывает локальный сайт по HTTPS. Код подставляется автоматически
в русском и английском клиентах, включая свой код комнаты из настроек лаунчера.
Вручную можно открыть **`https://АДРЕС_СЕРВЕРА/?code=КОД&ref=qr`**.
Браузер телефона может запросить исключение для локального HTTPS-сертификата.

В настройках лаунчера QR-оверлей можно выключить. Там же есть отдельный переключатель автостарта:
когда комната достигнет лимита игроков и VIP-кнопка «Все в сборе» станет доступна, LocalBox отправит
игре то же действие `start`, что и эта кнопка.
Читы включаются в настройках лаунчера: впишите свой игровой ник и включите подсветку ответов.
Для Бредовухи и Смертельной вечеринки LocalBox ищет ответы в установленных играх Steam.
Если игра установлена отдельно или используется перевод, выберите её папку в поле
«Папка игры с ответами». Можно выбрать весь Jackbox Pack или `steamapps/common`.
После изменения настроек перезапустите сервер и войдите под указанным ником.
Панель открывается вкладкой справа или **Ctrl+Shift+K**; при ручном входе выберите комнату.
Подробности и ограничения — [админские читы](cheats.md).

## Порты

Движок слушает **80, 443, 38202, 38203**. На Linux порты 80/443 требуют прав (`setcap`/root); на Windows — не требуют.

Если при старте `EADDRINUSE :80` / `:443` — порт занят другой программой:

```sh
# Linux:
sudo ss -ltnp | grep -E ':(80|443)\b'   # найти процесс (nginx/caddy/apache)
sudo systemctl stop nginx caddy apache2  # остановить нужное
```

На Windows — закрой IIS/Skype или запусти лаунчер от администратора (`netstat -ano | findstr :80`).

Если `EADDRINUSE :38203` — висит старый движок:

```sh
sudo pkill -9 -f server/server.js; sudo fuser -k -9 38203/tcp
```

## Английский / русский интерфейс

Лаунчер берёт основным русский `client-ru/` (если есть), иначе английский `client/`.
Поддерживаются обе структуры [DdejjCAT/jackbox.tv](https://github.com/DdejjCAT/jackbox.tv):
старая (`script-0.js`, `main/pp7/quiplash3/script.js`) и новая
(имена JS/CSS с хешами, `main/pp7-quiplash3/`). Формат выбирается автоматически по
`index.html` и таблице модулей клиента. Переключатель и переименование файлов не нужны.
Коды из QR-ссылок, ручной ввод кириллицы и админская панель работают с обеими структурами.
Недостающие картинки и другие файлы автоматически ищутся в обеих соседних папках `client/` и
`client-ru/`, независимо от выбранного клиента. При совпадении путей используется файл выбранного
клиента; явно заданный `LOCALBOX_CLIENT_FALLBACK` имеет приоритет перед остальными дополнительными
папками. При поиске учитываются вложенные и плоские папки одной игры, но имя файла
должно совпадать: картинка с другим хешем не подставляется. Если файла нет локально, фирменные ассеты jackbox.ru (задники, логотипы)
**докачиваются с jackbox.ru и кэшируются**, когда докачка включена.
Имена картинок в английской и русской сборках могут отличаться. Загрузчик проверяет ссылки
в скачанных CSS, JS и HTML, включая уже сохранённые файлы. При первой загрузке пути
берутся из `index.html` и таблицы модулей скачиваемой сборки, а не из имён файлов другой
версии в `client/`. Английский клиент для загрузки русского не обязателен.
Для восстановления неполного клиента:

```sh
node tools/fetch-fun.js --host jackbox.ru --dst client-ru --repair
# Только Quiplash 3 (main/pp7-quiplash3 тоже распознаётся):
node tools/fetch-fun.js --host jackbox.ru --dst client-ru --repair --only main/pp7/quiplash3
```

Чтобы принудительно использовать английский интерфейс и сохранить русские картинки, задайте
`LOCALBOX_CLIENT_DIR` при прямом запуске сервера: `LOCALBOX_CLIENT_DIR=../client node server.js`
из папки `server/` (Linux) или `set LOCALBOX_CLIENT_DIR=../client`, затем `node server.js` (Windows).

## Как добавить новую игру (например The Jackbox Party Pack 12)

Движок **сам регистрирует любую игру** при создании комнаты (берёт `appId`, `appTag`, число игроков прямо из запроса). Поэтому:

1. **Подключение работает сразу** — ничего в движке менять не надо, даже для новых паков.
2. Нужны только **клиентские ассеты** игры для телефонов. Они подтягиваются автоматически:
   - если jackbox.ru/jackbox.tv уже поддерживают пак — онлайн-докачка возьмёт недостающее при первой загрузке (интернет один раз, потом кэш);
   - либо положи папку игры вручную в `client/` и/или `client-ru/`.

**Явно прописать игру** (задать лимиты игроков) — по желанию, в `server/games.json`:

```jsonc
"appTags":    { "новый-тег": "APP-ID-игры", ... }
"appIds":     { "APP-ID-игры": "новый-тег", ... }
"maxPlayers": { "новый-тег": 8, ... }
"minPlayers": { "новый-тег": 1, ... }
```

`appId` и `appTag` видно в **логе движка** при запуске игры (строка `POST /api/v2/rooms`). После правки `games.json` перезапусти движок.

## Додо Ре Ми (nopus-opus)

Игра требует серверный рендер выступления в mp3 — движок собирает его локально через `ffmpeg`.
Если ffmpeg не находится в системном PATH (бывает после установки через winget) — можно просто
положить `ffmpeg.exe` (Windows) / `ffmpeg` (Linux/macOS) в `runtime/` в корне проекта, движок
подхватит его напрямую, без PATH.
Настройка ассетов (бэкинги песен, инструменты) и громкости — в [docs/dodo-re-mi.md](dodo-re-mi.md).

## Озвучка (TTS)

Игры вроде Mad Verse City требуют голосовой синтез — движок озвучивает локально/офлайн
(Silero/Piper/espeak, на выбор в настройках лаунчера). Установщик загружает выбранные голоса,
а меню запуска показывает только готовые локальные модели с установленными библиотеками.
Установка под Windows и Linux,
частые ошибки (в т.ч. `onnxruntime`/DLL на Windows) — в [docs/tts.md](tts.md).
