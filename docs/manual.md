# Ручная настройка LocalBox

Обычно хватает установщика из [Releases](https://github.com/zAsQwE/localbox/releases): он сам ставит
всё нужное. Эта страница — для установки из исходников и для случаев, когда что-то не работает.

Из исходников проще всего запустить в папке проекта `./setup.sh` (Linux) или `install.bat` (Windows):
они сами поставят зависимости. Ниже — то же полностью вручную.

## 1. Что нужно

| Программа | Зачем |
| --- | --- |
| Node.js 18+ (с npm) | сам сервер |
| Python 3.10+ с Tk | лаунчер |
| git | скачать проект и английский клиент |
| ffmpeg | Додо Ре Ми и сжатие озвучки (необязательно) |

**Windows:** установите [Node.js LTS](https://nodejs.org) и [Python](https://python.org). В установщике Python
отметьте **«Add python.exe to PATH»**. git — с [git-scm.com](https://git-scm.com).

**Linux:**

```sh
sudo apt install nodejs npm python3 python3-tk git ffmpeg     # Debian / Ubuntu
sudo pacman -S nodejs npm python tk git ffmpeg                # Arch / CachyOS
sudo dnf install nodejs npm python3 python3-tkinter git ffmpeg # Fedora
```

Если в вашем Debian/Ubuntu Node.js старше 18, поставьте свежий с [nodejs.org](https://nodejs.org/en/download).

## 2. Скачать LocalBox

```sh
git clone https://github.com/zAsQwE/localbox
cd localbox
```

Или скачайте ZIP со страницы проекта и распакуйте. Путь к папке — **без пробелов**, на Windows ещё
и без кириллицы, например `C:\LocalBox` или `~/LocalBox`.

## 3. Веб-клиент для телефонов

Клиент не входит в репозиторий, его скачивают отдельно. Хватит одного из двух:

- **Английский** — в папку `client`:
  ```sh
  git clone https://github.com/DdejjCAT/jackbox.tv client
  ```
- **Русский** — кнопка **«Скачать русский клиент»** в лаунчере (после шага 4) или команда:
  ```sh
  python3 tools/fetch-jackbox-ru.py
  ```

## 4. Запуск

- Windows: `start-server.bat`.
- Linux: `./start-server.sh`.

Меню спросит, открыть окно или консоль, включить ли Додо Ре Ми и какой голос взять. Затем в лаунчере:

1. Проверьте в **«Настройках»** IP компьютера: он должен быть из вашей сети, например `192.168.1.108`.
2. Нажмите **«Запустить сервер»**.

При первом запуске лаунчер сам ставит зависимости сервера, создаёт сертификат в `certs/`, а на Linux
один раз просит пароль, чтобы сервер мог занять порты 80 и 443. На Windows при первом запуске разрешите
Node.js доступ к сети в окне брандмауэра.

## 5. Подключить игру

Нажмите **«Копировать serverUrl»** и вставьте строку в Steam: **игра → Свойства → Параметры запуска**.

- **Windows:** строка — `-jbg.config serverUrl=IP`. При ручной установке один раз нажмите в настройках
  **«Обновить сертификат»** и ответьте «Да» в окне Windows. Без этого игры не подключатся
  к серверу.
- **Linux:** вставляйте строку целиком, она длинная, так и должно быть. Свои параметры
  (например `--renderer=OpenGL`) дописывайте в конец **через пробел**.
- **Trivia Murder Party 3:** нажмите **«Патч Trivia Murder Party 3»** и выберите в игре локальный сервер.
- **Игра на другом компьютере:** та же строка с IP компьютера, где запущен LocalBox. На Windows там тоже
  нужен LocalBox и один раз «Обновить сертификат» с IP сервера.

## 6. Подключить игроков

Игроки сканируют QR-код на экране: откроется сайт с уже введённым кодом комнаты. Или открывают
`http://IP_компьютера`. Телефоны должны быть в той же сети, сертификат им не нужен.

В **«Настройках»** можно выключить QR, выбрать его угол экрана и включить автостарт, когда комната заполнится.

## Друзья через Porthole

[Porthole](https://store.steampowered.com/app/4963920/) делится портом со Steam-другом без настройки роутера.

1. Запустите LocalBox и игру как обычно.
2. В Porthole создайте лобби и поделитесь портом **TCP 80**.
3. Друг открывает `http://127.0.0.1`. Кнопка **«Ссылка для друга»** копирует адрес сразу с кодом комнаты.

Если у друга порт 80 занят, впишите в лаунчере в поле **«Порт»** рядом с Porthole, например, `9999`
и перезапустите сервер. Делитесь этим портом, друг открывает `http://127.0.0.1:9999`. Порт 80 для игроков
по Wi-Fi продолжает работать. Если Porthole не нужен, снимите галочку **«Поддержка Porthole»** в настройках.

## Если что-то не работает

| Что видно | Что сделать |
| --- | --- |
| В журнале сервера `[tls] … не доверяет сертификату` | Windows: **«Обновить сертификат»**. Linux: скопируйте строку запуска заново, целиком. В журнале игры (`TJPP2-log.txt` и т. п. в папке игры) должно быть `Using specified CA Bundle`. |
| Linux: игра падает с `vkDeviceWaitIdle: Invalid device` | Допишите в конец параметров запуска ` --renderer=OpenGL` (с пробелом перед ним). |
| Игра долго «подключается», в журнале сервера пусто | IP в настройках не совпадает с IP компьютера, или сервер не запущен. Проверьте IP и строку запуска. |
| Телефон не открывает сайт | Телефон в другой сети (гостевой Wi-Fi, мобильный интернет) или Windows не пустил Node.js через брандмауэр. |
| На сайте нет игры, предлагается **«Обновить клиент»** | Нажмите кнопку: скачается свежий английский клиент. |
| `EADDRINUSE :80` или `:443` | Порт занят другой программой (nginx, Apache, IIS, Skype). Найдите её: `sudo ss -ltnp \| grep -E ':(80\|443)\b'` на Linux, `netstat -ano \| findstr :80` на Windows. |
| `EADDRINUSE :38203` | Висит прошлый сервер: `pkill -f server/server.js` (Linux) или закройте `node.exe` в диспетчере задач. |
| Linux: `EACCES` на порт 80/443 | `sudo setcap cap_net_bind_service=+ep "$(readlink -f "$(command -v node)")"` |
| `HTTP 422 game_disabled` | Игры Jackbox 12 выключены переменной `LOCALBOX_ENABLE_PACK12=0`, уберите её. |

## Справка

### Параметры лаунчера

| Команда (из папки `launcher`) | Что делает |
| --- | --- |
| `python3 localbox_launcher.py` | окно лаунчера (без дисплея — консольный сервер) |
| `python3 localbox_launcher.py -ip=192.168.1.108` | консольный сервер на этом IP |
| `python3 localbox_launcher.py -ip=192.168.1.108 -no-web` | только игровой сервер, без сайта для телефонов |
| `python3 localbox_launcher.py --offline` | консольный сервер, ничего не докачивать из интернета |
| `python3 localbox_launcher.py --check` | проверить node, сервер и клиент |

### Порты

Сервер слушает **80** (сайт и игроки), **443** (HTTPS для игр), **38202** и **38203** (старые игры на Blobcast).
Если включён свой порт Porthole, к ним добавляется он.

### Сертификаты

LocalBox создаёт свой сертификат (CA) в `certs/` без интернета и никогда не заменяет его сам.
Телефонам и браузерам он не нужен: они заходят по `http://`. Нужен он только играм:

- **Windows** берёт CA из хранилища Windows — галочка в установщике или кнопка **«Обновить сертификат»**.
  Удалить: `certmgr.msc` → «Доверенные корневые центры» → LocalBox.
- **Linux:** LocalBox ничего не меняет в системе и в Steam, сертификат передаётся только строкой запуска.
  Linux-версии паков читают его из `-cafile`, Windows-версии под Proton — из `SSL_CERT_FILE`.
  `protocol=http` отправляет запрос создания комнаты по HTTP. Файл `certs/localbox-ca-bundle.pem`
  обновляется при каждом запуске сервера.
- **Trivia Murder Party 3** — свой файл сертификатов в папке игры, его ставит патч.

LocalBox не меняет `hosts`, DNS и файлы игр (кроме патча TMP3).

### Язык и веб-клиент

Язык меняется в **«Настройках» → «Сервер»**. В русском интерфейсе телефоны получают `client-ru`, если он
есть, иначе `client`; недостающие картинки сервер ищет в обеих папках и при включённой настройке
докачивает с jackbox.ru. Для игры совсем без интернета снимите в настройках обе галочки скачивания
или запускайте с `--offline`.

Починить неполный русский клиент: `python3 tools/fetch-jackbox-ru.py` (докачивает только недостающее,
`--force` — заново, `--dry-run` — показать, что будет скачано).

### Новые игры

Сервер сам запоминает новую игру по её `appTag`. Задать лимит игроков можно в `server/games.json`
(`maxPlayers`, `minPlayers`); `appTag` видно в журнале сервера в строке `POST /api/v2/rooms`.
После правки перезапустите сервер.
