# Озвучка (TTS) — установка и настройка

Некоторые игры (например **Mad Verse City** — «Город злых рифм») просят сервер озвучить
текст (в оригинале — платный AWS Polly). LocalBox озвучивает **локально и офлайн** — выбор
голоса и движка настраивается в лаунчере («⚙ Настройки» → «Озвучка»).

> Игру TTS не ломает в любом случае: если ни один движок не завёлся, сервер отдаёт **тишину**
> нужной длины (`silent`) — игра не виснет, просто без голоса.

---

## Движки — какой выбрать

| Движок     | Качество            | Что нужно поставить                          | Разовая загрузка       |
| ---------- | -------------------- | --------------------------------------------- | ----------------------- |
| **silero** | Лучшее (нейро)        | `pip install torch numpy`                     | модель ~60 МБ            |
| **piper**  | Хорошее, легче/быстрее | `pip install piper-tts`                       | голос ~20–60 МБ          |
| **espeak** | Робо-голос            | `espeak-ng` (системный пакет, НЕ pip)          | нет                      |
| **silent** | Без голоса            | ничего не нужно                               | —                        |
| **auto**   | (по умолчанию)        | пробует silero → piper → espeak → тишина     | —                        |

Голос выбирается там же, в выпадающем списке (список меняется в зависимости от движка).
Кнопка **«▶ Прослушать»** в настройках генерирует короткий образец, не заходя в игру —
ей и удобнее всего проверять, что установка прошла успешно.

---

## Установка — Windows

### Silero (рекомендуется, если не жалко ~1 ГБ на torch)

```
pip install torch numpy
```

Модель (v4_ru, ~60 МБ) скачается один раз при первом использовании — дальше офлайн.

### Piper (легче и быстрее)

```
pip install piper-tts
```

**Частая ошибка на Windows** — при попытке синтеза:

```
ImportError: DLL load failed while importing onnxruntime_pybind11_state:
A dynamic link library (DLL) initialization routine failed.
```

Piper использует `onnxruntime` (нативная C++ библиотека) — на Windows ей почти всегда не
хватает **Visual C++ Redistributable**. Почини так:

1. Поставь VC++ Redistributable x64 (официальный линк Microsoft):
   https://aka.ms/vs/17/release/vc_redist.x64.exe — и перезагрузи ПК.
2. Проверь, что Python **64-битный**: `python -c "import struct; print(struct.calcsize('P')*8)"`
   должно вывести `64`. Если `32` — переставь 64-битный Python с python.org.
3. Если не помогло — переустанови начисто:
   ```
   pip uninstall onnxruntime piper-tts -y
   pip install --upgrade piper-tts
   ```
4. Если у тебя очень новый Python (3.13+) и под него ещё нет готового wheel'а onnxruntime —
   поставь venv на Python 3.11/3.12 и укажи путь к нему в настройках лаунчера, поле
   **«Python для TTS»** (см. ниже) — не обязательно переустанавливать основной Python.

### espeak-ng (самый лёгкий, робо-голос)

Готовых pip-пакетов для Windows нет — ставится как обычная программа:

1. Скачай инсталлятор с https://github.com/espeak-ng/espeak-ng/releases (файл вида
   `espeak-ng-*-x64.msi`).
2. Поставь — инсталлятор сам добавляет `espeak-ng` в PATH.
3. Проверь в новом окне cmd: `espeak-ng --version`.

## Установка — Linux

### Silero

```sh
pip install torch numpy
```

На Arch/CachyOS иногда нужен `python-pip` отдельно: `sudo pacman -S python-pip`.

### Piper

```sh
pip install piper-tts
```

На Linux `onnxruntime` обычно ставится без проблем (нативных DLL-заморочек Windows тут нет).
Если всё же ошибка при импорте — почти всегда дело в несовместимой версии Python; попробуй
venv на 3.11/3.12 (см. «Python для TTS» ниже).

### espeak-ng

```sh
# Arch/CachyOS
sudo pacman -S espeak-ng
# Debian/Ubuntu
sudo apt install espeak-ng
# Fedora
sudo dnf install espeak-ng
```

`./setup.sh` эти системные пакеты сам не ставит (это выбор пользователя, не обязательное
условие для запуска сервера) — espeak и Python-пакеты (torch/piper) нужно ставить руками
по этой инструкции.

## Настройка в лаунчере

- **Движок** / **Голос** — выпадающие списки в «⚙ Настройки» → «Озвучка».
  - Silero: `eugene` (по умолч.), `baya`, `kseniya`, `xenia`, `aidar`, `random`.
  - Piper: `ru_RU-denis-medium` (по умолч.), `ru_RU-dmitri-medium`, `ru_RU-irina-medium`,
    `ru_RU-ruslan-medium`.
- **Python для TTS** — пусто = тот же python, которым запущен лаунчер. Укажи путь к python
  из отдельного venv (например, на 3.11/3.12), если основной Python слишком новый и
  ML-библиотеки (torch/onnxruntime) под него не ставятся или падают с DLL/импорт-ошибками.
  Это самый надёжный обходной путь для проблем совместимости версий, если советы выше
  не помогли.
- Настройки сохраняются в `launcher/localbox-settings.json` и применяются **при следующем
  запуске сервера** (не на лету).

## Диагностика / частые ошибки

| Сообщение / симптом                                                        | Причина / решение                                                                 |
| --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `ImportError: DLL load failed ... onnxruntime_pybind11_state` (Windows)     | Нет VC++ Redistributable — см. «Установка — Windows → Piper» выше.                  |
| `No module named 'torch'` / `'onnxruntime'` / `'piper'`                     | Пакет не установлен в ТОМ python, который использует сервер — проверь поле «Python для TTS». |
| Silero: `не установлен torch/numpy`                                         | `pip install torch numpy` (в правильный python — см. выше).                          |
| Piper: `нужен pip install piper-tts`                                        | `pip install piper-tts`; на Windows отдельно поставь VC++ Redistributable.          |
| Piper: `wave.Error: # channels not specified`                               | Голос скачался НЕПОЛНОСТЬЮ (нужны ДВА файла — `<голос>.onnx` и `<голос>.onnx.json`, а есть только первый — обычно из-за обрыва сети/сна устройства при скачивании). Удали папку `server/tts/piper/` и попробуй ещё раз — движок перекачает голос заново. |
| `espeak: command not found` / `ESPEAK: нет`                                 | Поставь `espeak-ng` — на Windows инсталлятором, на Linux пакетным менеджером (см. выше). |
| Голос есть, но игра всё равно молчит                                       | Проверь лог сервера при старте — строка `[tts] движок: ... espeak: ... ffmpeg: ...` показывает, что реально нашлось. |
| Долго генерирует первый образец                                             | Нормально для Silero/Piper — скачивается модель (один раз, нужен интернет), дальше офлайн и быстро. |
| Нет звука при нажатии «▶ Прослушать» (файл создался, а не играет)          | Нужен аудиоплеер: `pulseaudio-utils` / `alsa-utils` (Linux) или просто есть `ffmpeg`/`mpv`/`vlc` в PATH. |

Если ничего не помогло — включи `LOCALBOX_DEBUG=1` при запуске сервера и пришли строку
`[tts] ...` из лога вместе с точным текстом ошибки.
