# Установщик LocalBox

Установщики лежат в **Assets** на странице [Releases](https://github.com/zAsQwE/localbox/releases).
Они скачивают последний стабильный Release LocalBox и всё, чего не хватает: Python, Node.js, ffmpeg,
веб-клиент и выбранные голоса. Уже установленные подходящие программы используются повторно.
Интернет нужен только на время установки.

## Windows

1. Запустите `setup.exe`. Прав администратора он не просит.
2. Выберите язык, папку LocalBox (путь без кириллицы и пробелов) и голоса.
3. По желанию: русский веб-клиент, папка Jackbox 10 для Додо Ре Ми, папка игр для читов, патч TMP3.
4. Оставьте галочку **«Сделать сертификат доверенным для игр Jackbox»** и нажмите **«Скачать»**.
   В конце Windows спросит про сертификат LocalBox — ответьте «Да».
5. Нажмите **«Открыть LocalBox»**. Дальше запускайте ярлык LocalBox или `start-server.bat`.

Журнал установки — `install.log` в папке LocalBox.

## Linux

```sh
chmod +x setup-linux.run
./setup-linux.run
```

Откроется окно с теми же настройками. Без дисплея вопросы задаются в терминале. Для недостающих
системных пакетов setup один раз попросит пароль; сам setup через `sudo` запускать не нужно.
Папка по умолчанию — `~/.local/share/localbox`, в меню приложений появится LocalBox.

Установка без вопросов:

```sh
./setup-linux.run --console --target "$HOME/LocalBox" --tts piper --voices ru_RU-denis-medium --ru
```

## Обновление

В лаунчере: **«Проверить обновления» → «Обновить до …»**. Архив проверяется до замены файлов,
при ошибке установка откатывается. Настройки, сертификаты, клиент, голоса и музыка сохраняются.
Можно и просто запустить setup ещё раз и выбрать ту же папку.

## Для автора: сборка и выпуск

Нужны Python 3.10+ и [NSIS](https://nsis.sourceforge.io/Download) (`makensis`) для `setup.exe`:

```sh
python3 tools/build-installers.py --version v1.2.0
```

В `dist/` появятся `setup.exe`, `setup-linux.run`, `localbox-update.zip` и `SHA256SUMS`.
Настройки, сертификаты, ключи, клиенты и `node_modules` в сборку не попадают.

**Проверка до публикации.** Обычный setup ставит опубликованный Release, а не свежую сборку.
Чтобы поставить код из самого установщика, запустите `setup.exe /local` или
`./setup-linux.run --local` и выберите пустую папку.

**Выпуск:**

1. Номер в `version.json` (или `--version`) должен совпадать с тегом, например `1.2` и `v1.2.0`.
2. Прикрепите к Release все четыре файла из `dist/`.
3. Опубликуйте Release без отметок draft и pre-release: такие установщик пропускает.
4. Проверьте `setup.exe` / `setup-linux.run` со страницы Release без ключей и обновление
   из лаунчера старой версии.

Русский клиент `client-ru.zip` достаточно прикрепить хотя бы к одному стабильному Release:
установщик берёт самый свежий. Добавить его в сборку:
`--client-ru-archive /путь/к/client-ru.zip`.
