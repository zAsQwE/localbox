# Установка LocalBox

Скачайте установщик из **Assets** на странице [Releases](https://github.com/zAsQwE/localbox/releases).
`Source code (zip/tar.gz)` — исходники для ручной установки.

`setup.exe` и `setup-linux.run` проверяют последний опубликованный стабильный
Release при каждой установке. Скачивается `localbox-update.zip`, проверяются SHA-256,
манифест и соответствие версии тегу; затем устанавливается выбранный Release.
Встроенная версия setup не влияет на выбор. Черновики и предварительные выпуски
не устанавливаются. Одна и та же копия setup подходит для последующих выпусков.
При ошибке загрузки или проверки установка останавливается, другая версия скрыто не подставляется.

Готовые артефакты сборки: `dist/setup.exe` для Windows 10/11 x64 и
`dist/setup-linux.run` для Linux. Это онлайн-установщики: файлы LocalBox включены,
зависимости, веб-клиент и выбранные модели загружаются во время установки.

Оба графических установщика показывают настройки в одном окне: папки, озвучку,
голоса, поддержку Додо Ре Ми и русский клиент. Кнопка «Скачать» запускает
загрузку и установку. После окончания она становится кнопкой «Открыть LocalBox».
Ошибки и ход установки доступны в раскрываемом журнале; параметры сохраняются
при повторной попытке.

Setup использует уже установленные совместимые зависимости. Windows проверяет
PATH, сохранённые пути, реестр и стандартные папки Python, Node.js и Git; Node.js
должен быть версии 18+ и иметь рабочий npm, Python — 64-битный 3.10+ с Tk и venv.
ffmpeg, Git, OpenSSL и mkcert также используются повторно. Linux проверяет PATH,
сохранённый Node.js, nvm, Volta и mise; системный пакет ставится только при необходимости.
Выбранные пути сохраняются для следующих запусков.

Размер окна ограничивается доступной областью экрана; на Windows учитывается DPI
текущего монитора. Настройки прокручиваются, а кнопка «Скачать» остаётся доступной.

Светлая и тёмная тема выбираются автоматически и обновляются при смене темы
окружения. Windows использует настройку темы приложений. На Linux предпочтение
читается через [XDG Desktop Portal](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.Settings.html),
с запасными вариантами для GNOME, KDE и GTK.

## Windows

1. Откройте `setup.exe` и выберите пустую папку приложения или существующий LocalBox.
2. Выберите папку зависимостей. По умолчанию это `<LocalBox>/runtime`.
3. Выберите Piper, Silero, оба движка или установку без озвучки. Для Piper отметьте
   нужные голоса: Денис, Дмитрий, Ирина и/или Руслан.
4. При необходимости включите Додо Ре Ми и укажите папку Jackbox Party Pack 10.
   Можно указать саму папку `games/NopusOpus/songs`. Музыка копируется в LocalBox.
5. По желанию отметьте «Указать папку с играми для читов» и выберите общий каталог
   с установленными Jackbox, `steamapps/common` или папку отдельной игры. Файлы читаются
   на месте и не копируются. Без этой галочки LocalBox ищет игры в библиотеках Steam.
6. Нажмите «Скачать», затем «Открыть LocalBox». Позже используйте `start-server.bat`
   или созданный ярлык LocalBox.

Python с Tk и pip устанавливается автоматически, если подходящего Python 3.10–3.13 x64
нет. Повторно используется имеющийся совместимый Python. В папку зависимостей
устанавливаются Node.js 22 LTS, ffmpeg, MinGit, mkcert и отдельное окружение TTS.
Для Piper при отсутствии нужного VC++ Runtime устанавливается Microsoft VC++
Redistributable x64; Windows может запросить разрешение на эту системную установку.
`winget` и ручное обновление PATH не нужны. Журнал — `<LocalBox>/install.log`.

Из исходников `install.bat` открывает `dist/setup.exe` или `setup.exe`, если он найден.
Иначе предлагает выбор TTS в консоли и устанавливает приложение в текущую папку.

## Linux

```sh
chmod +x setup-linux.run
./setup-linux.run
```

В графической сессии откроется окно с настройками и кнопкой «Скачать». Если Python или Tk отсутствуют, bootstrap
сначала установит их через пакетный менеджер. Без дисплея вопросы задаются в терминале.
Папка приложения по умолчанию — `~/.local/share/localbox`. Из исходников достаточно
`./setup.sh`: по умолчанию приложение остаётся в текущей папке, путь можно изменить.

```sh
./setup.sh --console
./setup.sh --target "$HOME/Games/LocalBox" --runtime "$HOME/Games/LocalBox-runtime" \
  --tts piper --voices ru_RU-denis-medium,ru_RU-irina-medium \
  --game "$HOME/.local/share/Steam/steamapps/common/The Jackbox Party Pack 10" \
  --cheat-content "$HOME/.local/share/Steam/steamapps/common"
```

Системные Python, Tk, Node.js 18+, npm, git, ffmpeg, OpenSSL и libcap
устанавливаются через apt, pacman, dnf или zypper с `sudo`/`pkexec`. На macOS поддерживается
Homebrew. Эти пакеты располагаются в системных каталогах, а TTS-библиотеки —
в выбранной папке зависимостей. На Linux дополнительно доступен eSpeak.
Создаётся пункт LocalBox в меню приложений. `--ru` загружает русский веб-клиент;
`--run` открывает лаунчер после установки.

## Запуск и голоса

`start-server.bat` и `start-server.sh` без аргументов задают одинаковые вопросы:
GUI или консоль, с Додо Ре Ми или без, затем готовый голос. Выбор сохраняется.
Обычный режим снимает галочку Додо Ре Ми, режим с поддержкой включает её.
Для голосов проверяются библиотеки выбранного Python и файлы локальной модели;
неполные Piper-модели в меню не показываются. Скачивания из меню запуска нет.
При отсутствии голосов доступен запуск без озвучки. Каждый устанавливаемый голос
проверяется синтезом до сохранения новых настроек.

При передаче аргументов меню пропускается, например `./start-server.sh --check`
или `./start-server.sh -ip=192.168.1.10`. Чтобы открыть меню вместе с аргументами,
передайте `--interactive`. `--gui` явно открывает GUI, `--server` запускает консольный сервер.

Мастер копирует `backing*.ogg` из папок песен и имеющиеся OGG-сэмплы из соседней
`instruments/`. Файлы установленной игры не изменяются. Если путь игры оставлен пустым,
поддержку рендера можно включить сразу и добавить музыку позднее; без бэкингов
будут звучать сыгранные ноты. Возможности рендера описаны в [Додо Ре Ми](dodo-re-mi.md).

## Сертификаты

LocalBox только создаёт сертификат сервера и ключи в локальной папке `certs/`.
OpenSSL и запасной mkcert не добавляют CA в доверие системы, браузеров или Steam.
Для генерации не запрашиваются права на изменение хранилищ сертификатов.
HTTPS может вызывать предупреждение браузера; игровые клиенты со строгой проверкой
цепочки TLS могут отклонять подключение. Старые записи в доверенных хранилищах
при обновлении не удаляются.

## Папки игр в настройках

В настройках лаунчера на вкладке «Музыка» можно выбрать Jackbox 10 или `songs`
и нажать «Импортировать музыку». Путь сохраняется вместе с настройками.
На вкладке «Оверлей» можно изменить общий каталог игр для читов; пустое поле включает
поиск в Steam. Для показа ответов впишите нужные ники в список администраторов.
Изменения настроек применяются после перезапуска сервера.

## Обновление из приложения

Кнопка «Проверить обновления» в лаунчере проверяет последний стабильный Release
`zAsQwE/localbox`. При наличии новой версии нажмите «Обновить до …»: архив
скачивается и проверяется по SHA-256 и манифесту до изменения файлов.
После загрузки сервер останавливается, обновление устанавливается отдельным
процессом и лаунчер открывается снова. Остановите игровую сессию заранее.

Обновляются файлы приложения и, при изменении package.json/package-lock.json,
зависимости Node.js. Настройки, сертификаты и ключи, клиент, TTS и музыка остаются
на месте. Неудачная загрузка не меняет установку; ошибка замены файлов запускает
откат. Копии с незакоммиченными изменениями исходников обновляются через Git.

Старый Release без `localbox-update.zip` не поддерживает этот способ обновления.
В таком случае скачайте setup вручную и выберите существующую папку LocalBox.

## Сборка и публикация Release

Установите [NSIS](https://nsis.sourceforge.io/Download) с `makensis` и Python 3.10+:

```sh
python3 tools/build-installers.py
python3 tools/build-installers.py --linux-only
python3 tools/build-installers.py --makensis /путь/к/makensis --output-dir dist
python3 tools/build-installers.py --version v1.2.0
```

Сборка Windows возможна на Linux с компилятором NSIS. `dist/SHA256SUMS` содержит
хеши артефактов; `installer/payload-sha256.json` внутри установщиков — хеши включённых файлов.
В комплект не входят пользовательские настройки, сертификаты, ключи, модели,
скачанные клиенты, `node_modules` и локальные тесты. Существующие настройки сохраняются при обновлении.

Номер установленной версии берётся из `version.json`. Для нового выпуска измените
этот файл или передайте `--version`; номер должен совпадать с тегом GitHub Release.
Например, для `v1.2.0` соберите с `--version v1.2.0` и прикрепите к Release все четыре файла:
`setup.exe`, `setup-linux.run`, `localbox-update.zip`, `SHA256SUMS`.
Архив обновления общий для Windows и Linux, вручную распаковывать его пользователю не нужно.
Этот же архив используется онлайн-установщиками: его отсутствие в последнем Release
не позволяет setup установить выпуск. Сначала прикрепите все файлы к черновику, затем публикуйте Release.

Из исходников `./setup.sh` устанавливает текущую копию проекта. `./setup.sh --latest`
запускает установку последнего Release. Для проверки встроенных файлов Linux-установщика
без запроса GitHub используйте `./setup-linux.run --local`; загрузка остальных зависимостей
по-прежнему может требовать интернет. `--extract-to ПАПКА` только распаковывает сборку.

Источники зависимостей: [Python и параметры тихой установки](https://docs.python.org/3.12/using/windows.html#installing-without-ui),
[Node.js и контрольные суммы](https://nodejs.org/dist/latest-v22.x/),
[ffmpeg Gyan](https://www.gyan.dev/ffmpeg/builds/),
[MinGit](https://github.com/git-for-windows/git/releases),
[mkcert](https://github.com/FiloSottile/mkcert/releases),
[Piper CLI](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/CLI.md),
[Silero](https://github.com/snakers4/silero-models).
